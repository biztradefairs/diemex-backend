# Visitor badge artwork

- `diemex-logo.png`: DIEMEX full-colour third-edition logo from the website's `public/images/diemex3.png`, supplied by the user for the badge.
- `Inter.ttf`: Inter variable font from https://github.com/google/fonts/tree/main/ofl/inter.
  Its SIL Open Font License is included in `OFL.txt`.

These local assets are bundled with the backend so WhatsApp badge generation does not depend on
website availability or fonts installed on the deployment host.
